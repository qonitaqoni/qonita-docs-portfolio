# Product Catalog API Reference

The Product Catalog API allows developers to retrieve catalog items, search for products, and simulate adding new products to inventory.

---

## Base URL

All requests in this reference interact with the live public endpoint: `https://dummyjson.com`

## Endpoints

### 1. Get Product by ID

Retrieve detailed information of a product.
* HTTP Method: `GET` 
* Path: `/products/{id}`

#### Parameters

| Parameter | Type | In | Description |
| :--- | :--- | :--- | :--- |
| `id` | `integer` | path | Required. The unique numerical identifier of the product (e.g. `1`). |

#### Request Examples

<Tabs defaultValue="curl" values={[
  { label: 'cURL', value: 'curl' },
  { label: 'JavaScript', value: 'js' },
  { label: 'Python', value: 'py' }
]}>

<TabItem value="curl">

```bash
curl -X GET "https://dummyjson.com/products/1" \
  -H "Accept: application/json"
```

</TabItem>

<TabItem value="js">

```javascript

const product = await response.json();

console.log(product);
```
  
</TabItem>

</TabItem>

</Tabs>

### 2. Search Products

Search for products in the catalog matching a query string.

* HTTP Method: `GET`
* Path: `/products/search`

#### Parameters

| Parameter | Type | In | Description |
| :--- | :--- | :--- | :--- |
| `q` | `string` | query | Requeired. The search keyword (e.g. `phone` or `laptop`). |

#### Request Examples

<Tabs defaultValue="curl" values={[
  { label: 'cURL', value: 'curl' },
  { label: 'JavaScript', value: 'js' }
]}>

<TabItem value="curl">

```bash
curl -X GET "https://dummyjson.com/products/search?q=phone"
```
  
</TabItem>

<TabItem value="js">

```javascript
const response = await fetch('https://dummyjson.com/products/search?q=phone');
const results = await response.json();

console.log(results);
```
  
</TabItem>

</Tabs>

#### Response Example (`200 OK`)

```json
{
  "products": [
    {
      "id": 121,
      "title": "iPhone 5s",
      "price": 199.99,
      "category": "smartphones"
    }
  ],
  "total": 1,

  "limit": 30
}
```


### 3. Create A New Product

Simulate adding a new item to the catalog database.

* HTTP Method: `POST`
* Path: `/products/add`

#### Request Body Schema

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | Yes | The name of the product. |
| `price` | `number` | Yes | Decimal selling price. |
| `category` | `string` | Yes | Product classification tag. |

#### Request Examples

<Tabs defaultValue="curl" values={[
    {label: 'cURL', value: 'curl'},
    {label: 'JavaScript', value: 'js'}
]}>
  
<TabItem value="curl">

```bash
curl -X POST "https://dummyjson.com/products/add" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Wireless Ergonomic Keyboard",
    "price": 89.99,
    "category": "electronics"
  }'
```

</TabItem>

<TabItem value="js">

```javascript
const response = await fetch('https://dummyjson.com/products/add', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: 'Wireless Ergonomic Keyboard',
    price: 89.99,
    category: 'electronics'
  })
});

const newProduct = await response.json();
console.log(newProduct);
```

</TabItem>

</Tabs>

#### Response Example (`201 Created`)

```json
{
  "id": 195,
  "title": "Wireless Ergonomic Keyboard",
  "price": 89.99,
  "category": "electronics"
}
```

### 4. Get Product by Filtering, Sorting, and Pagination

Retrieve large collections of products using query parameters to optimize payloads and filter results. 

#### Parameters

| Parameter | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `category` | `string` | Filters product by category | `?category=smartphones` |
| `limit` | `integer` | Maximum number of records to return (Default: 20, Max: 100) | `?limit=10` |
| `skip` | `integer` | Number of records to skip for pagination offsets | `?skip=20` |
| `sortBy` | `string` | Field to sort records by `price`, `title`, `rating` | `?sortBy=price` |
| `order` | `string` | Sort direction of records by `asc` or `desc`| `?order=asc` |

#### Request Examples

<Tabs defaultValue="curl" values={[
  {label: 'cURL', value: 'curl'},
  {label: 'JavaScript', value: 'js'}
]}>

<TabItem value="curl">

```bash
curl -X GET "https://dummyjson.com/products/search?q=phone&limit=5&skip=0" \
  -H "Accept: application/json"
```

</TabItem>

<TabItem value="js">

```javascript
const params = new URLSearchParams({
  q: 'phone',
  limit: '5',
  skip: '0'
});

const response = await fetch('https://dummyjson.com/products/search?${params}');
const data = await response.json();
console.log(`Found ${data.total} products.`);
```

</TabItem>

</Tabs>


## Standardized Error Response

In the event of client or server error, the API return standard error payload in JSON conforming to HTTP semantics with an error code and diagnostic message.

### Response Example

```json
{
  "error": {
    "code": "INVALID_QUERY_PARAMETER",
    "message": "The provided 'limit' parameter exceeds the maximum allowed value of 100.",
    "status": 400,
    "timestamp": "2026-10-24T17:00:00Z"
  }
}
```


### Status and Error Codes

| Status Code | Description |
| :--- | :--- |
| `200 OK` | The request succeeds and returning matched JSON data. |
| `201 Created` | New product is successfully added. |
| `400 Bad Request` | Missing required request body parameters. |
| `404 Not Found` | The product `id` requested does not exist in the database. |
